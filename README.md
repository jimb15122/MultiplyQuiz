A little web app for math practice.  

Enter a name, and choose difficulty by entering the maximum number value to use in the problems.

Tap a problem type to generate the 25 random problems and start the timer.

When last answer is entered, results and history are shown.  Emojis are displayed reflecting accuracy and speed ratings and history includes trophies for best results in each quiz type. (➕➖✖️➗)

Designed for use on mobile screens.

Can be saved on home screen, and launched as a web app.
